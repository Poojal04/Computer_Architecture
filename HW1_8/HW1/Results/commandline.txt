For each SPEC application there is a directory with it name, this directory is called
the application's home directory. The home directory of an application contains its
32-bit static binary and input files.

Executing Applications
----------------------
You must execute an application from its home directory only. If run from any other directory
the applications may not execute correctly. Below we describe how to run the 400.perlbench application:
	cd 400.perlbench/
	./perlbench_base.i386 -I./lib diffmail.pl 4 800 10 17 19 300 > perlbench.ref.diffmail.out 2> perlbench.ref.diffmail.err

The application 482.sphinx3 has a slightly different home directory structure, you must execute it as follows:
	cd 482.sphinx3/
	cd 1/2/482.sphinx3/
	./sphinx3_base.i386 ctlfile . args.an4 > sphinx3.ref.out 2> sphinx3.ref.err
